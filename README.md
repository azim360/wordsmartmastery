# Word Smart 1 & 2 Mastery

A web-based flashcard application built to help master 793 advanced vocabulary words. Organized into 16 study drills, it features a library catalog interface, study progress tracking, and mobile-friendly swipe navigation.

## Features
* **Progress Tracking:** Saves your "Got it" vs "Study Again" metrics.
* **Responsive Design:** Optimized for both desktop browsers and mobile touch screens.
* **Quick Search:** Instantly find any word in the dictionary.
* **Offline Ready:** Operates as a Progressive Web App (PWA).

## Built With
* HTML5
* Vanilla CSS
* Vanilla JavaScript (No external frameworks)
